## 프로젝트 및 팀 소개

저희는 2025 명지대학교 팀프로젝트 1의 team5입니다.
해당 프로젝트는 총 6개의 서비스 팀과 1개의 inner 아키텍쳐팀, 1개의 outer 아키텍쳐팀 총 8개의 팀으로 나누어 구현되었습니다.
학생 식당 개선 웹사이트는 학식을 이용하는 학생들의 리뷰를 수집하고 분석하여 식당이 개선을 목표로 하는 서비스입니다.

저희 team5는 **msi 프로젝트인 학생 식당 개선 웹사이트** 중 사용자의 리뷰를 받는 서비스와 퀴즈 서비스, 먹고 싶은 메뉴 입력 서비스와 맛집 제공 서비스를 맡았습니다.
